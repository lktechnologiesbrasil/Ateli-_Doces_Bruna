## 1. Objetivo

Criar a landing page/site institucional do Ateliê Doces Bruna, com forte trabalho de branding, identidade visual, storytelling e presença digital. **DIREÇÃO:** o site é “a casa digital da marca”, não apenas mais um canal de venda. Deve apresentar a marca, a Bruna, a história, o Ateliê, os produtos, a loja física, o trabalho artesanal, encomendas, prova social, presença local, canais de atendimento e o ecossistema digital existente.

Objetivo emocional: quando a Bruna vir o projeto, pensar “UAU, eu estava precisando disso”. O projeto **eleva** o que já existe; não cria outra personalidade para a marca.

## 2. Marca

- Nome: **Ateliê Doces Bruna**. Instagram: `@ateliedocesbruna`. (OBSERVADO)

## 5. Problema que o projeto resolve

Os canais existem mas estão **fragmentados**; falta um ponto central que responda: quem é a Bruna, o que é o Ateliê, qual a história, por que existe, o que o torna especial, como é o espaço, o que é produzido, como comprar, como encomendar, como visitar e por que confiar. A landing page ocupa essa lacuna.

## 6. Público e jornadas

Público principal: **A CONFIRMAR** com a Bruna. Quatro jornadas (DIREÇÃO):

1. **Compra imediata:** site → desejo → “Pedir agora” → Yooga.
2. **Encomenda:** site → trabalho/bolos → “Fazer uma encomenda” → WhatsApp.
3. **Visita à loja:** site → ambiente, localização/horário → Google Maps.
4. **Branding/descoberta:** Google/Instagram → site → história → Bruna → produtos → prova social → confiança → pedido futuro.

Pedir agora e encomendar são fluxos **separados**; nunca misturar.

## 7. Direção de branding

Editorial + artesanal + humano + gastronômico + delicado + contemporâneo + premium acessível. Fotografia real como protagonista, muito espaço em branco, grids editoriais controlados, serifada elegante em títulos e sans-serif legível em UI/corpo (fontes **não** definidas; licenciamento a respeitar). Referência: “marca editorial de confeitaria artesanal”, não “template de doceria”. Evitar: rosa chiclete, visual infantil, cupcake genérico, ornamentos, estética de marketplace/delivery, preto dominante, neon, luxo artificial. Prioridade máxima para **material real**; não depender de stock.

## 8. Landing page proposta

Landing institucional premium com âncoras (Início, O Ateliê, Bruna, Criações, Encomendas, Loja, Contato) e CTA persistente **Pedir agora**. Seções iniciais: Header → Hero → Manifesto → Bruna → Criações → Momento de desejo → Feito à mão/bastidores → Loja física → Como pedir → Prova social → Instagram → CTA final → Footer. Mensagem existente da marca “Doces incríveis para transformar o seu dia!” entra no processo criativo (não é H1 definitivo). “Feito para ser lembrado.” e “Que tal um doce?” são apenas direção criativa, **não slogans confirmados**. Detalhes: `05_LANDING_PAGE_ARCHITECTURE.md`; estratégia/SEO/UX: `04_WEBSITE_STRATEGY.md`.
