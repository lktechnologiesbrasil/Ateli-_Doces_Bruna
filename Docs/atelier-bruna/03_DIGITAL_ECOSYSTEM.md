## Arquitetura inicial (DIREÇÃO)
```
SITE
├── apresentação da marca, storytelling, criações, loja, prova social, SEO
├── PEDIR AGORA ──────> Yooga
├── ENCOMENDAR ───────> WhatsApp
├── VER INSTAGRAM ────> Instagram
└── COMO CHEGAR ──────> Google Maps
```
A separação é estratégica: o site não substitui as plataformas.

## Problema
Instagram + Yooga + WhatsApp + Google + Linktree resolvem funções específicas, mas não há um ponto central que conte quem é a Bruna, o que é o Ateliê, a história, o porquê, o diferencial, o espaço, o que é produzido e como comprar/encomendar/visitar/confiar.
